账户列表、详情和分享判断共用有效状态规则，首次使用账户不会被查询激活。重复资源 ID 返回稳定的 409 冲突。只读配置按统一敏感字段策略处理，完整配置仅管理员可读。

后台刷新在抓取期限内保留完成结果，按最久未检查优先推进；任务同时展示执行状态、业务结果、是否发布和待后续处理数量。无效资源更新保留已验证资源，失败任务也保存报告。

普通账户分享支持可选的链接到期时间和下载次数，仍受权益、scope 和 profiles 限制。原生前端保留按需加载、请求取消、草稿保护和移动端布局，任务区域能在延迟加载后继续收到实时事件。

生产程序保持模块化单体：clientprofile 定义输出能力，subscription 处理纯解析/计划/编译，accounting 处理权益与计量，manage 组合 HTTP、任务和主机操作。没有为历史数据保留运行时迁移层。

domain 承载稳定的分页、选项、入站身份和任务权限类型；accounting/controlstore 不再反向依赖应用用例。三个工作队列独立接收通知；调度合并由可信来源控制，不再依赖用户名。面板任务重试带持久回执，已受理请求返回原任务编号。VPNGate 档案删除受凭据引用校验保护，切换国家保留其他档案的绑定。前端继续使用原生 ES 模块、共享表单、可折叠高级字段及现有窄屏布局。

application 负责纯账户节点投影，manage 注入证书读取与已应用状态；任务执行只接收 ClaimedTask。账户名称约束由领域层发布给前端，分享列表接入可取消的可见页刷新。连接授权缓存保留值类型周期和截止时间，查询缓冲可复用且不跨 goroutine 暴露。

当前检查结果仅以本轮记录及对应 GitHub Actions 为准。历史报告保存在 Git 历史中，不作为当前源码的验证结果。

发布字段统一校验，最终导出再次校验；部署预览与执行共用精确服务计划。探测使用独立队列并支持持久取消，前端按服务端能力显示操作。持久计量去除重复 SQL 查询并复用批次缓冲，保留 WAL/FULL 与预留后转发语义。

搜索多选、卡片格式选择、顺序调整和自由多值输入沿用统一模型；绑定必须提供非空入口 ID，默认选择当前快照。凭据轮换支持自定义值，后台失败通过脱敏概览提示；权益、任务和证书历史分别限时清理，超时后的审计具有独立预算。分发共享任务级账户仓储，订阅发布拒绝未确认代际。

证书续期只依据已应用登记，应用失败的待应用配置不会阻断续期。证书调度状态归 certificates，订阅调度判定归 subscription，手动/自动任务统一由 application 分发。订阅命令拒绝无效作用范围；证书状态和命令联合类型由 Go 生成。关键 API 模块额外启用 strict；表格使用稳定标识和动作签名，焦点刷新及原地修改不会执行过期操作。

已确认配置的恢复启动与候选证书验证分离；过期证书不阻断后台续期，也不放行 TLS 握手。证书页面合并草稿、已保存和已生效登记，操作能力由后端提供，仍生效的 ID 不能被新资产复用。

普通入站的 UDP 额外端口直接属于节点，防火墙、冲突校验和账户导出共用该归属。订阅投递确认与运行历史从节点缓存拆到 operations.json，普通投递只提交小型状态文件；刷新和投递复用服务仓储。请求对象复用减少持久计量分配，未改变持久性和额度边界。

高级订阅公开下载只使用已确认版本，按 HTTP 最终响应原子计次。编译快照记录实际来源，下载、投递与状态页统一校验这些来源的权益及新鲜度。绑定只查询目标账户和入站的关系，账户任务统一批处理；分享迟到结果可主动找回，不覆盖新弹窗或取消新页面。面板设置、管理员/MFA、用户分组及账户写入继续接入 Go 生成端点契约。
