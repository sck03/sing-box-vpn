## 前一阶段：导航、分享与服务命名

- 导航分组从 11px 放大到 15px，支持键盘/鼠标展开收起并记忆；当前页面所在分组会展开。
- 权益页集中管理时间、流量、绑定、分享和撤销。用户分组为高级可选功能；普通分享自动生成 ID，不再要求第二个到期时间或下载次数。高级订阅编译工作区默认收起。
- 新增「公网访问」及仅管理员可用的设置预览/保存接口，校验 TLS、域名、代理和端口冲突，版本冲突返回 409。保存和实际生效配置分开显示，明确重启后生效；回环 URL 在创建令牌前拒绝。
- 面板 TLS 读取当前证书，续期后新连接使用新材料；面板引用证书不会被孤立材料清理误删。
- 服务统一为 `sing-box`、`vpngate-core`、`vpngate`、`subscription`、`argo`，安装/升级/卸载和恢复同步使用当前名称；不提供旧别名。职责和功能入口由后端服务登记提供给前端。

公网部署、服务分工与上游固定提交比较见[公网访问与系统服务](public-access.md)。本轮验证与清理结果见[当前验证记录](validation/2026-11-18-panel-access-services.json)。GitHub main 提交与正式发行包不同，更新安装包仍需发布 Release；没有向生产 VPS 部署或向公网 CA 申请域名证书。

## 前一阶段：版本入口与证书查询优化

- 修复安装器将正式发行限制在 v4 的错误。采用与发布工具一致的正式标签语法，通过包内管理器、受管核心和维护文件判断安装内容，不按 Release 主版本猜测平台格式。
- 菜单不再固定显示 v4；已安装版本由管理器返回，读取有时间上限。在线入口会随安装保留，发行包内较早脚本不会覆盖入口修复。
- Linux 上已验证 v4/v5/v6/v12 标签、amd64/arm64 包结构、保留入口后的升级、非法标签、残缺包、摘要和归档保护；对 GitHub 实际 v5.0.0 包验证了 SHA256、原生程序版本和保留后的菜单显示。该项没有执行生产主机安装。
- PEM 匹配/域名/有效期逻辑集中到 `certificate_material.go`，供导入、状态和续期复用；状态查询减少重复文件读取、证书解析与引用扫描。32 资产本地基准耗时中位数由 19.82 ms 降至 10.40 ms，分配字节由 1,064,581 B 降至 580,349 B。
- 按全新部署范围移除 `certbot` 兼容分支；配置仅接受 `acme` / `import`，不增加旧数据或旧接口迁移。

本轮管理包全部 Go 测试、Go vet、五组页面测试及 ShellCheck 已通过；Linux amd64 上的 PEM/ACME 回归与 arm64 管理器交叉构建通过。新增回归覆盖 PEM 匹配、域名、有效期边界、Go 叶证书解析开关、旧提供方拒绝、申请/续期和发布状态。详细命令、原始基准与边界见 [本轮验证记录](validation/2026-11-18-version-and-certificates.json)。新增 Go 改动需新发行包部署，main 上的在线入口修复可用于现有 v5.0.0 包；不改写已发布的归档。

## 前一阶段：一键安装与 lego

- `install.sh` 可通过文件、管道或进程替换运行，提供安装、升级和维护菜单；卸载调用本机脚本，支持确认提示及显式 `--yes`。该阶段的 v4 标签限制已在本轮移除。
- 生产安装不再需要 Python/Certbot。管理员输入通过 stdin 交给 Go；OpenVPN 保留为 VPNGate 的系统后端。
- 证书统一使用 lego v5.6.0，当前接入 HTTP-01、Let's Encrypt 和 ECDSA P-256。账户与签发结果原子保存，续期复用账户，发布失败复用签发结果，任务取消后释放验证监听。
- 该阶段曾读取历史 `certbot` 资产标记，现已按全新部署范围移除。本项目移除 CertMagic 显式依赖，发布器检查两种架构均不链接 CertMagic/acmez。

本地全量 Go 测试、Go vet、五组页面测试、ShellCheck、安装/升级/所有权脚本回归以及 Linux amd64/arm64 构建通过。Windows 和专用 Linux VM 中的本地 ACME 测试 CA 覆盖真实 HTTP-01 请求、申请、续期、缓存复用、拒绝签发、任务取消与发布状态；没有向公网 CA 申请真实域名证书。arm64 只完成交叉构建，本地未运行 Windows race。

可复核范围与命令见 [lego 与安装器本地验证记录](validation/2026-11-18-lego-installer.json)。本节不沿用旧提交的 GitHub CI 成功结论；新增代码的 CI 结果以对应 main 提交的运行记录为准，分支推送不等于发布正式 Release。

## 先前平台重构已实施

- 修复 SQLite 查询取消后物理连接重建导致外键、busy timeout 与 trusted_schema 丢失。连接策略由 DSN 逐连接执行，并覆盖取消、显式替换与孤立记录拒绝测试。
- 新增独立 `internal/gatewayconfig`，统一管理器、网关与页面的配置边界；未知字段、非法超时、容量、DNS 与来源在保存前拒绝。
- 移除 `app.warp` 和旧 local 来源。WireGuard 统一使用端点列表；简单分流、候选构建、账户导出消费相同配置模型。
- 完整草稿通过唯一配置预览入口校验。候选模式拒绝不兼容输出，运行数据暂不可用单独展示；准备好的来源缓存保存在持久任务中，应用时复用并重新验证。
- 公开分享入口允许跨站导航，管理 API 保留 Origin、Cookie 与 CSRF 检查。前后端密码按相同 UTF-8 字节范围验证。
- 服务单元写入前全量检查归属；安装失败和卸载不再按名称操作其他程序的单元。符号链接和不匹配的归属标记拒绝。
- 64 节点探测总预算调整为 8 分 24 秒，普通控制任务仍为 5 分钟。取消后仍保存已完成的脱敏结果，明确标记未执行节点。
- 页面按需加载，概览、维护、安全及字段规则独立成模块。补齐协议认证/TLS/Reality/WS、网关证书/端口、Geo/DNS、服务开机启动、操作员网关控制、远程模板和 Webhook。
- 订阅使用六个工作区；任务、账期、审计与网关信息结构化展示。运行状态工作区显示远端来源/模板/规则同步与 Webhook 最后发送结果；只读状态不暴露 URL、缓存正文或凭据。导出统一使用客户端目录，二维码按需生成；移动端保留排序入口。
- 空闲 SSE 发送 22 字节 tick；账户页继续刷新用量，流量变化不会禁用未过期的操作。用户页支持刷新、主题和分享地址切换的取消保护。
- 旧配置/凭据/端口写入器及旧预览辅助代码移出生产包；协议矩阵通过现行账户导出获得测试材料，保留安全和真实链路回归。
