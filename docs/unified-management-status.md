## 一键安装与 lego（2026-11-18）

- `install.sh` 可通过文件、管道或进程替换运行，提供安装、升级和维护菜单；`sb upgrade` 下载并校验正式 v4 包，卸载调用本机脚本，支持确认提示及显式 `--yes`。
- 生产安装不再需要 Python/Certbot。管理员输入通过 stdin 交给 Go；OpenVPN 保留为 VPNGate 的系统后端。
- 证书统一使用 lego v5.6.0，当前接入 HTTP-01、Let's Encrypt 和 ECDSA P-256。账户与签发结果原子保存，续期复用账户，发布失败复用签发结果，任务取消后释放验证监听。
- 历史 `certbot` 资产标记仍能读取，执行统一走 lego；本项目移除 CertMagic 显式依赖，发布器检查两种架构均不链接 CertMagic/acmez。

本地全量 Go 测试、Go vet、五组页面测试、ShellCheck、安装/升级/所有权脚本回归以及 Linux amd64/arm64 构建通过。Windows 和专用 Linux VM 中的本地 ACME 测试 CA 覆盖真实 HTTP-01 请求、申请、续期、缓存复用、拒绝签发、任务取消与发布状态；没有向公网 CA 申请真实域名证书。arm64 只完成交叉构建，本地未运行 Windows race。

可复核范围与命令见 [lego 与安装器本地验证记录](validation/2026-11-18-lego-installer.json)。本节不沿用旧提交的 GitHub CI 成功结论；新增代码的 CI 结果以对应 main 提交的运行记录为准，分支推送不等于发布正式 Release。

## 先前平台重构已实施

- 修复 SQLite 查询取消后物理连接重建导致外键、busy timeout 与 trusted_schema 丢失。连接策略由 DSN 逐连接执行，并覆盖取消、显式替换与孤立记录拒绝测试。
- 新增独立 `internal/gatewayconfig`，统一管理器、网关与页面的配置边界；未知字段、非法超时、容量、DNS 与来源在保存前拒绝。
- 移除 `app.warp` 和旧 local 来源。WireGuard 统一使用端点列表；简单分流、候选构建、账户导出消费相同配置模型。
- 完整草稿通过唯一配置预览入口校验。候选模式拒绝不兼容输出，运行数据暂不可用单独展示；准备好的来源缓存保存在持久任务中，应用时复用并重新验证。
- 公开分享入口允许跨站导航，管理 API 保留 Origin、Cookie 与 CSRF 检查。前后端密码按相同 UTF-8 字节范围验证。
- 服务单元写入前全量检查归属；安装失败和卸载不再按名称操作其他程序的单元。符号链接和不匹配的归属标记拒绝。
- 64 节点探测总预算调整为 8 分 24 秒，普通控制任务仍为 5 分钟。取消后仍保存已完成的脱敏结果，明确标记未执行节点。
- 页面按需加载，概览、维护、安全及字段规则独立成模块。补齐协议认证/TLS/Reality/WS、网关证书/端口、Geo/DNS、服务开机启动、操作员网关控制、远程模板和 Webhook。
- 订阅使用六个工作区；任务、账期、审计与网关信息结构化展示。运行状态工作区显示远端来源/模板/规则同步与 Webhook 最后发送结果；只读状态不暴露 URL、缓存正文或凭据。导出统一使用客户端目录，二维码按需生成；移动端保留排序入口。
- 空闲 SSE 发送 22 字节 tick；账户页继续刷新用量，流量变化不会禁用未过期的操作。用户页支持刷新、主题和分享地址切换的取消保护。
- 旧配置/凭据/端口写入器及旧预览辅助代码移出生产包；协议矩阵通过现行账户导出获得测试材料，保留安全和真实链路回归。
