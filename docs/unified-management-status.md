## 运行与账本语义

- 核心固定 sing-box 1.14.4，适配版本 1.14.4+sbvpn.2，独立于面板/下载进程。普通与 VPNGate 进程隔离，可共享权益额度。
- quota_bytes 的 null 表示不限，0 表示零额度。认证后有效载荷只计一次，不重复计入后端 VPN 隧道。
- 先持久预留再转发，累计检查点幂等。每权益每实例未用与在途预留至多 64 KiB；正常退出退款，崩溃保守保留。方向计数可能落后最后一批，不承诺断电零误差。
- 每 250 ms 集中检查并在 I/O 边界复核授权；过期、禁用、代次/周期改变阻止旧流继续转发。调度和在途数据不构成绝对停用时延保证。
- 凭据变更需要重启受影响的活动实例加载新用户，会影响其余连接。撤销旧代次不依赖重启成功，失败不会恢复旧授权。
- 账本和撤销记录属于持久证据，不按日志策略删除；需监测磁盘并定期加密备份，不可直接删除 lease/账期以免重放重新发放额度。
- 集群、支付、设备识别、带宽/IP 限制、任意脚本插件不在本单机版范围。

## 依赖与分发

采用免费开源依赖，已查询并更新可独立升级的稳定版 SQLite 1.62.0、YAML 3.0.6、x/crypto 0.59.0 及网络/系统库等。前端无生产 npm 依赖，开发验证使用 jsdom 31.0.1。SagerNet forks/pseudo-version、uTLS/QUIC 配套版本随固定核心保留，经真实链路验收再更新，不混用未经验证的开发主线。

系统工具采用 Debian/Ubuntu 软件源稳定包。go.mod/go.sum/package-lock.json 锁定版本；scripts/update-notices.py 整理 Linux/Windows 67 个实际链接模块的许可。官方 npm audit 为 0 个已知漏洞，不代表所有 Go/系统依赖都不存在漏洞。

发行包包含 Linux amd64/arm64 两个程序、源码和许可，Shell 脚本统一 LF。分支 push 只触发验证，tag 或显式发布才创建 GitHub Release。

## 验收

本轮已通过：

- 全量 go test ./...、go vet ./...；accounting/adminauth/controlstore/domain race；安全、周期、并发额度、加密备份/灾难恢复回归。
- 五协议双账户隔离/禁用及受管核心普通/VPNGate TCP/UDP 真实客户端矩阵。
- 12 页 DOM 渲染、只查看不改草稿、资源复制、operator 范围；Node 语法、ShellCheck，双架构构建。
- Linux VM 空目录真实安装，HTTP 登录/账户/绑定/导出/二维码/首次使用授权；配置应用保留停止态。
- Linux IPv4/IPv6 多端口防火墙。
- Linux systemd 防火墙丢失/异常干净退出恢复、OpenVPN/netns 无泄漏隔离；活动态和停止态程序升级；端口冲突后恢复旧配置及 active/enabled 状态。

升级脚本的停止/活动/失败回滚场景，以及延迟面板重启成功/失败恢复回归通过。面板延迟重启由独立服务执行，任务结束仅表示替换阶段结束，最终状态以该服务日志和面板实际启动为准。

未取得的验收证据：浏览器控制工具因无法可靠确定当前 URL 停止，尚无真实点击和移动布局结果；未跑所有协议到期/耗尽/轮换 TCP+UDP 完整交叉矩阵、真实断电/满盘和长时高规模吞吐。公网 ACME、Cloudflare/WARP、志愿 VPNGate 节点可用性不由本地测试保证。不能将实现完成表述为全部生产稳定性验收完成。
