## 运行与账本语义

- 核心固定 sing-box 1.14.4，适配版本 1.14.4+sbvpn.2，独立于面板/下载进程。普通与 VPNGate 进程隔离，可共享权益额度。
- quota_bytes 的 null 表示不限，0 表示零额度。认证后有效载荷只计一次，不重复计入后端 VPN 隧道。
- 先持久预留再转发，累计检查点幂等。每权益每实例未用与在途预留至多 64 KiB；正常退出退款，崩溃保守保留。方向计数可能落后最后一批，不承诺断电零误差。
- 每 250 ms 集中检查；I/O 边界复用按凭据代次共享的最长 250 ms 授权缓存，到期/周期边界提前失效，同 Store 更新立即失效。跨进程策略变化受缓存、数据库和调度延迟影响；不承诺绝对停用时延。
- 凭据变更需要重启受影响的活动实例加载新用户，会影响其余连接。撤销旧代次不依赖重启成功，失败不会恢复旧授权。
- 正常结清的 lease 通过运行代次高水位压缩，保留重放保护标记；未结清崩溃 lease、账期和撤销证据保留。连续崩溃的保守占用可以累积，不能手工删账释放额度。
- 集群、支付、设备识别、带宽/IP 限制、任意脚本插件不在本单机版范围。

## 依赖与分发

采用免费开源依赖，已查询并更新可独立升级的稳定版 SQLite 1.62.0、YAML 3.0.6、x/crypto 0.59.0 及网络/系统库等。前端无生产 npm 依赖，开发验证使用 jsdom 31.0.1。SagerNet forks/pseudo-version、uTLS/QUIC 配套版本随固定核心保留，经真实链路验收再更新，不混用未经验证的开发主线。

系统工具采用 Debian/Ubuntu 软件源稳定包。go.mod/go.sum/package-lock.json 锁定版本；scripts/update-notices.py 整理 Linux/Windows 67 个实际链接模块的许可。官方 npm audit 为 0 个已知漏洞，不代表所有 Go/系统依赖都不存在漏洞。

发行包包含 Linux amd64/arm64 两个程序、源码和许可，Shell 脚本统一 LF。分支 push 只触发验证，tag 或显式发布才创建 GitHub Release。

## 本次审查修订

- TCP 读取跨越 64 KiB 预留边界时继续申请，真正耗尽才终止，保留已计费前缀。
- 计量锁按额度池拆分；I/O 缓存命中不执行 SQL 或分配定时器；只写变化的检查点；结清失败保留待结算池供关闭重试。
- 权益与输出授权统一到 download_grants，null/0 语义一致，撤销立即持久化；订阅者禁用检查覆盖导出、下载与分发。
- 远程模板/规则正文与 ETag 持久缓存，重建和 304 不丢失；URL/资源变更清理缓存；刷新不改写配置 revision。
- VPNGate 启停作为带 revision 的配置任务持久化，网关仅消费投影；空闲订阅调度不写无效任务。
- 分享链接使用下载服务地址；概览更新保留搜索、页码和焦点，迟到的旧会话响应被丢弃。保存期间的新编辑保留为未保存草稿；校验与差异预览使用同一快照，重新载入隔离旧请求。
- 备份解码及 Base64 请求按 96 MiB 预算处理，读取数据库/证书前检查大小并约束累积内存。
- HTTP 账户查询和导出直接使用结构化结果；下载监听与构建复用 SQLite 连接；删除旧备份格式和重复调度。
