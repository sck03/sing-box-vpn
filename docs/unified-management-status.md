## 本次完成

- 抽出 `clientprofile`，统一 13 种客户端的模式、协议、特性和验收标记；表单联动、授权和导出共用目录。移除无效的最低版本字段。实验客户端不再被描述为已经实机认证。
- 渲染与探测共用筛选；拒绝保留策略组名称及无法保留的显式安全/传输参数，通用 TLS URI 保留指纹；检查分别报告最终产物验证与 sing-box 连通性。
- 必需账户停用、到期或删除时撤下依赖输出；恢复/刷新时隔离渲染和校验失败，面板保留修复入口。
- 账户列表复用快照、凭据按账户/实例索引读取、导出证书解析复用；用量检查点每轮同一事务提交，写数据库时释放池锁。保留 64 KiB 持久预留和 FULL 同步边界。
- 拆出任务 worker，控制副作用串行、只读探测独立执行；任务之间调度、自动任务去重。概览/SSE 共用缓存，systemctl 合并服务查询。
- 备份恢复改为二进制 multipart；灾难恢复 CLI 使用 `backup_path`。单个面板进程限制一个备份/恢复重操作，拒绝重复或未知 multipart 字段；恢复应用固定预览 revision，拒绝覆盖期间产生的新配置。
- 前端分组导航、响应式布局和焦点样式；防重复提交、离页取消请求、短暂断网保留草稿、隐藏字段不阻断提交；用户页支持代理子路径和刷新。静态资源 ETag 复用，敏感数据不缓存。
- 更新使用、订阅、架构、开发、兼容性与性能文档；删除过期设计文档，历史证据通过固定提交保留。

## 本地验证

Windows amd64，Go 1.27.3，sing-box 1.14.4、Mihomo 1.19.33：

- 全量 `go test ./... -count=1` 通过；后续订阅和管理改动再次通过相关完整模块测试。
- 五协议受管账户隔离通过；普通/VPNGate × sing-box/Mihomo/provider/URI 的 36 组配置通过真实 TCP+UDP 共 72 条链路。4 个 VMess/TUIC 自签 URI 场景明确跳过，原因是 Mihomo 导入器忽略对应 TLS 参数；原生格式已覆盖。
- 全部 Go 模块竞态检查通过。首次全量运行只有网关的子进程退出广播用例超时：Windows 竞态程序启动约 6.1 秒撞上原 5 秒期限，放宽启动期限至 30 秒并保留独立 1 秒清理断言；连续复测 3 次及完整网关竞态重跑均通过。后续数据库、恢复预览和全部客户端下载/计数回归单独通过竞态检查。
- `npm test` 通过：12 页 DOM、角色范围、草稿/并发加载/旧会话、重复提交、客户端字段联动、隐藏的未完成 JSON、断网和子路径下载。
- `go vet ./...`、Go 格式检查、ShellCheck 通过。

- Linux amd64/arm64 管理器和受管核心发行包构建通过。13 种客户端格式的 HTTP 下载、授权保护和累计计数通过；实验客户端使用共同支持的 VMess WS 样例，不代表全部协议组合认证。

首轮 Linux CI 的全量竞态、72 条链路、受管账户隔离、升级脚本、OpenVPN/netns、IPv4/IPv6 防火墙、systemd 恢复和双架构构建通过。最终安装回滚脚本发现概览缓存未在新任务入队时失效，短时间查不到刚提交的任务；已在入队、开始和完成时统一失效，并补充“入队立即可见”回归。最终结果以对应提交的 GitHub Actions 记录为准。Windows Git Bash 缺少 `flock`，本机不执行升级系统专项。

## 验证边界

浏览器工具无法可靠识别 Windows 当前网址并停止界面控制，本轮没有真实浏览器点击、截图或移动端视觉验收。DOM 回归不能替代这部分结果。

Surge、Surge Mac、Loon、Quantumult X、Surfboard、Stash、Egern、Shadowrocket 尚无实际应用导入证据；OpenClash 尚无实体路由器验收。Mihomo 分流核心检查要求本机 `Country.mmdb`，缺失时明确报告未完成核心校验。长期大规模吞吐、真实断电/满盘、全部公网 ACME/Cloudflare/VPNGate 服务不在本轮本机验证范围。

没有以执行路径优化推导 CPU/RSS 或吞吐提升百分比。预留上限和计量误差语义见[使用指南](usage.md)，格式与特性边界见[订阅文档](subscriptions.md)。分支推送不等于创建 Release 或部署生产。
