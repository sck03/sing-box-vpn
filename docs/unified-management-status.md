# 部署前优化与验收记录

更新：2026-11-17。面向首次部署：数据库 schema 7、备份格式 7、平台配置 schema 4、订阅配置 schema 1。不提供旧数据库、旧备份或旧接口迁移。历史测试证据见 [本轮之前的固定提交](https://github.com/sck03/sing-box-vpn/tree/461cb61)。

## 实施范围

- 正确性：备份在发布锁内捕获数据库快照和关联证书，锁外加密；创建与恢复都校验证书/私钥匹配。灾难恢复保留 certbot 所属信息，缺少续期注册文件时重新排队，并显示待注册状态。服务启动和证书更新共用运行时就绪检查。
- 生命周期：有效授权和失效记录分别计数；失效授权保留最多 1,000 条/30 天。已结束任务保留 200 条/30 天，结果详情按 UTF-8 字节限制在 8 MiB，清理详情仍保留探测结论。账期保留最近 120 期，存在未结清预留时不清理；撤销凭据和计量防重放记录不随普通历史清理。
- 容量：格式 7 使用 tar + age 流式加密，HTTP 备份先生成临时加密文件，限制总包 96 MiB、数据库 80 MiB、证书 2,048 个且单文件 1 MiB。恢复输入和解密材料仍使用有界内存；没有将恢复声称为全流式或整个进程固定 RSS。
- 热路径：批量读取活跃凭据授权、同账户账期推进复用、入站绑定索引；保留 64 KiB 持久预留和 SQLite WAL/FULL。概览合并在途读取且不在 I/O 期间持状态锁；订阅探测的编译校验移出材料捕获锁。
- 模块：账户绑定用例放入 application，通过仓储边界执行；备份容器独立为 backuparchive；旧配置/订阅/远程推送命令仅保留测试适配器，生产程序不再携带旧 CLI 入口。
- 前端：修复渲染状态不能搜索、实时刷新重建操作按钮丢失焦点；未变化数据不重绘。授权改为服务端分页并显示到期/耗尽状态；GiB/天输入、表单内错误、主题切换、移动导航、角色导航与跨页任务提示；概览优先展示在线实例及失败任务。
- 开源参考：s-ui 的业务分层、Zashboard/metacubexd 的交互组织、Gluetun 的就绪与故障恢复思路。未复制上述源码；具体对应关系见 [上游记录](upstream.md)。

## 验证边界

浏览器工具无法可靠识别 Windows 当前网址并停止界面控制，本轮没有真实浏览器截图或移动端视觉验收，DOM 回归不能替代视觉验收。

公网 ACME 签发、第三方 VPNGate 线路质量、真实断电与物理磁盘损坏、生产规模长时间满载需要在实际部署环境验收。隔离文件系统的 ENOSPC 注入用于检查写入失败语义，不代表硬件断电测试。Surge、Loon 等闭源客户端和 OpenClash 实体路由器仍无本轮实机认证。

## 清理原则

本轮清理旧生产命令入口、remote.json 通知旁路及重复界面代码；仍被回归引用的适配器明确保留在测试文件。虚拟机内本轮临时状态、凭据、辅助程序及测试服务已清理，原始测量汇总保存在 `docs/validation/`。本机批量删除被自动审批规则拒绝（blocked by policy），按用户授权将 `.test/quality/`、`.test/perf-baseline/` 统一移入 `待手动删除/2026-11-17-*`，该目录被 Git 忽略，可整体手动删除。保留开发工具、必要依赖缓存、虚拟机基础磁盘和当前双架构安装包；测试虚拟机已停止。
