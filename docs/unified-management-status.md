# 部署前重构与验收记录

更新：2026-11-18。本轮基于 `b018c92`，面向首次部署：数据库 schema **10**、备份容器格式 **7**、平台配置 schema **4**、订阅配置 schema **1**。旧数据库及包含旧数据库的备份明确拒绝，不迁移旧数据或接口。

## 实施结果

- 初始化稳定性：管理员预校验，首管理员与配置同事务提交。投影失败保留初始化标记，重试发布已提交配置，避免半初始化目录无法继续。
- 请求隔离：HTTP 连接与生命周期归入 `internal/httpserver`。面板普通请求与 SSE 各有独立的 32 个执行槽位，总连接上限 128；流连接占满时，管理 API 仍可响应。可信反代从 X-Forwarded-For 右侧逐级确定真实客户端，避免伪造链头绕过登录限制。
- 查询和依赖：概览只读 revision，任务摘要直接读 outcome 独立列；下载复用已打开的账户/配置仓库，账户导出只依赖所需的配置读取接口，避免重复打开数据库及读取无关大字段。
- 流量预留：每个 Store 按需创建有界写队列，合并已排队请求，最多 64 个共享一次磁盘提交；无合批等待定时器。SAVEPOINT 隔离单项失败，FULL 提交成功后才返回可转发字节，保留每池 64 KiB 预留边界和崩溃保守计费。
- 授权生命周期：下载次数耗尽后仍能查询账户用量，用户页显示原因并隐藏下载入口；这类账户授权计入容量上限，只有撤销或到期才按失效历史清理。
- 草稿一致性：`POST /api/country` 使用 `{country,config}`，基于当前草稿生成候选配置；前端拒绝覆盖请求期间被重载或编辑的草稿。
- 前端模块与体验：账户、订阅者、授权、路由、出站、VPNGate 分模块，页面请求与跨页面工作流分别管理生命周期，会话结束统一取消。新增路由/DNS、VPNGate 策略与 WireGuard 对端表单。表格缓存搜索/排序值，实时更新保留焦点并禁用过时操作。统一深浅主题、卡片、页头、间距、表格与移动端样式。
- 精简：仅测试使用的旧初始化和订阅设置入口移入 `legacy_*_test.go`，不编入生产；去掉拆分后的无用导入，更新接口、数据库、资源边界及开发文档。
- CI：全量 race 显式使用 25 分钟测试时限，验证作业总时限调整为 45 分钟，为后续 Linux 系统验收与双架构构建留出时间，避免再次触及 Go 默认 10 分钟限制。

前轮配置快照、订阅自动恢复、主机恢复及账户策略字段重构已包含在本轮基线，历史细节见 [b018c92 记录](https://github.com/sck03/sing-box-vpn/blob/b018c92/docs/unified-management-status.md)。

## 验证边界

11 月 18 日续接时，内置浏览器与 Chrome 绑定分别报 `constraints`、`timeoutMs` 内部错误；原生窗口检查随后因无法可靠确认当前 URL 被工具停止。因此本轮未完成真实桌面/移动端截图与视觉验收。已完成 DOM 功能回归，不能据此声称实际布局已验收。

本轮未重新执行完整 Linux 安装/升级、systemd、防火墙/netns 矩阵、公网 ACME、第三方 VPNGate 志愿线路、物理断电、整机重启或长期满载。相关 CI 步骤保留；历史 Linux 系统测试结果不能冒充本轮结果。闭源客户端与实体 OpenClash 路由器需对应环境验证。

## 清理与交付

无用临时二进制、基线归档和面板测试数据集中到仓库根目录 `.cleanup-manual/`，可整体手动删除。11 月 18 日已核对清理路径位于工作区内且没有符号链接或运行中的二进制，但自动审批仍以 `blocked by policy` 拒绝删除；按用户指定的备选方式，将续接测试文件也归入同一目录。原中文待删除目录已归入其中，避免 Go 包扫描报非法路径。该目录被 Git/Go 扫描忽略，不进入发行包。保留许可证、回归夹具、开发工具、必要缓存及虚拟机基础磁盘；测试服务器和虚拟机均已停止。

交付目标为 GitHub `main`，合并所有有效工作后仅保留本地与远端 `main`。当前完整发行包位于 `.build/release/`。提交推送不等于正式发布 Release、生产部署或 GitHub Actions 通过。
