# 部署前重构与验收记录

更新：2026-11-17。本轮基于 `78d8539`，面向首次部署：数据库 schema **8**、备份容器格式 **7**、平台配置 schema **4**、订阅配置 schema **1**。只接受当前数据库和接口，不迁移旧数据。此前性能测量保留在 [性能与资源边界](optimization.md)，不代表本轮重新实测。

## 实施结果

- **凭据发布可靠性**：绑定、轮换、解绑与发布版本同事务提交。分别记录持久版本、产物版本和核心已加载版本；失败后自动补发布和必要的重启，不重复轮换。已停止的核心保持停止；“已加载”不等于当前在线。重试从 5 秒检查开始，失败逐步退避至 5 分钟。
- **模块边界**：HTTP 按账户、订阅/授权、配置和任务拆分，共享认证、Host/Origin、CSRF 与审计边界。分页和刷新结果由 application 定义；accounting 负责账本查询与凭据事务；hostservice 负责不依赖数据库的失败服务恢复；备份容器独立于 HTTP。
- **资源占用**：账户列表改成 SQL 分页、搜索和排序，仅推进当前页账期；轻量账户/入站选项避免加载完整账本。凭据查重改为唯一索引，批量绑定仅清理一次事件历史。空工作队列先只读检查，配置校验移出状态互斥锁。保留 SQLite WAL/FULL 和 64 KiB 持久预留。
- **恢复与稳定性**：新增每 5 分钟加随机延迟的 systemd 恢复定时器，只处理固定名单、固定路径且带项目标记的 failed 服务；不接管其他服务或拉起 inactive 服务。任务、凭据恢复和升级共用服务操作锁。升级和回滚等待本次启动后的新核心心跳。损坏订阅缓存隔离后重建；上游失败返回 cached/partial/failed 等明确结果。
- **备份与材料清理**：HTTP 恢复先把密文写临时文件，再通过 Reader 解密，移除一份最大 96 MiB 密文内存副本；仍有明文、密钥派生和数据库开销，不承诺固定 RSS。证书清理保护 desired/applied 引用和 7 天宽限，只清理带标记的直属材料目录。
- **前端**：拆分 DOM、表格与实时连接模块；统一 SSE 生命周期、退出/隐藏清理及指数重连，断线保留草稿。账户服务端分页/排序，表格列显隐和密度偏好，更新保留焦点；绑定使用资源多选。维护页实时显示任务和部分失败，概览同时考虑配置、凭据、服务与心跳。统一主题颜色、边框和表格工具布局。
- **修复**：VPN 空映射导致的崩溃、订阅授权页错误及重复列表、维护页状态不刷新、停用订阅者状态遗漏、恢复上传临时文件残留，以及 Linux 测试对 disabled 返回码的错误判断。升级测试修正了否定断言未使脚本退出的问题。

设计参考与固定源码版本见 [上游记录](upstream.md)。没有复制 s-ui、Zashboard、metacubexd 或 Gluetun 源码。

## 验证边界

浏览器工具在创建/读取本地页面时持续报告内部 `constraints` / `timeoutMs` 参数错误，因此没有完成真实浏览器截图、移动端和视觉验收；DOM 回归不能替代视觉验收。

本轮没有重新进行 CPU/RSS/吞吐对照、长时间满载或整机重启实验。公网 ACME、第三方 VPNGate 线路、物理断电/磁盘损坏以及闭源客户端和 OpenClash 实体路由器仍需实际部署环境验收。systemd 恢复检查不等于端到端业务探测；受管核心就绪另由心跳判断。
