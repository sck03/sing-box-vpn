**连接回退、崩溃恢复与 UDP 转发优化 · 2026-11-05**

以提交 2ea48ed 为本轮基线，保留普通/VPNGate 五协议、分流、凭据、证书、Argo/CDN、

- 守护进程被 SIGKILL 后，下一次启动会回收已确认归属的命名空间中残留的 OpenVPN/worker。
  清理使用共同截止时间，检查命名空间、veth 和项目防火墙链，确认完成后才移除所有权记录。
  清理失败或无法读取资源清单时保留记录，允许重试，避免永久卡在“资源存在但无所有权”。
- UDP 数据帧直接复用已有缓冲的两个字节前缀，将每帧的两次 Write 合并为一次，不复制负载，

- SOCKS UDP 地址头按会话缓存，缓存最多 256 项，与最多 128 个目标会话一起回收；
  已有目标不再逐包分配地址字符串。IPv4 和表示同一 IPv4 的域名地址头仍共用原会话，
