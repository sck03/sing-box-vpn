## 模块与资源

证书资产/材料模块位于 internal/certificates，发行身份与资产校验位于 internal/deployment。管理层负责配置事务、任务和服务恢复，前端共享 secret-field、certificate-fields、certificate-editor，并独立维护程序更新与模板导入视图。新增 API 与模型纳入生成契约和实际 API 验收。

删除未使用的官方校验器直接激活路径；仅用于旧回归夹具的校验/服务 helper 放到 \_test.go，不进入发行二进制。移除过时的 DNS independent_cache，并让后端明确拒绝该字段。VPNGate 初始化统一目录格式，消除 Windows 下配置重载的错误目录比较。

自动证书维护先查询轻量 revision，仅在配置改变或十分钟截止到达时读取完整配置和 PEM；读取材料有尺寸上限。访问页并行读取独立数据。账本 WAL/FULL、额度预留、撤销检查和代理独立运行的保证保持原语义。

## 普通使用流程

1. 安装后在自己的电脑运行 SSH 转发命令并登录。概览中的「首次使用」可随时展开。
2. 在用户与分享中创建权益并绑定入站。节点本身不提供所有人共用的认证凭据。
3. 需要公开 HTTPS 时，先申请/导入匹配域名的证书并应用；自动证书申请成功后，在系统设置的公网访问中选择证书。
4. 面板访问设置先预览、再保存，点击重启使其生效；独立订阅是平台草稿，需要顶部校验并应用。
5. 在用户权益中分享订阅。需要多来源编排时再使用订阅模板、规则和输出。

默认面板设置文件是 /etc/s-box/panel.json，自定义 SB_ROOT 时位于对应目录。日常配置无需手动编辑该文件。直接 HTTPS 内置 TLS，无需另装 Nginx/Caddy；选择反向代理则需要事先配置代理服务。

## 更新和模板边界

检查更新查的是本项目正式发行包。lego 是程序内置签发组件，随整包更新；证书是续期或替换。不能用任意官方 sing-box 直接替换受管运行时，否则会失去本项目账户计量。未来版本需要继续通过组件配套、当前配置及连接验收，没有无条件兼容所有上游版本的保证。

外部完整模板仅提取可明确转换的简单规则，不复制节点凭据、脚本、DNS 或设备配置。多条件规则不能无损转换时整次导入报错，不会偷偷丢规则。来源地址、提交/版本和 SHA256 用于追溯，不等同于上游官方认证。实验客户端仍标记实验适配。

验证结果见 [本轮验收记录](validation/2026-11-20-ux-component-refactor.json)。历史验收记录继续保留；实际源码推送与 GitHub Release 发布分别进行，推送 main 不等于 VPS 已升级。
