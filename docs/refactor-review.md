## 模块与资源边界

证书查询抽至 certificate_status.go，页面抽至 certificate-page.js；公网策略与证书材料验证分别负责启动和候选边界。订阅操作记录独立成模块，继续使用现有发布日志和锁，不引入第二套持久化机制。删除 App 全局端口字段、首入站推导和重复证书查找，VPNGate Profile 在节点转换边界映射统一字段。

面板沿用原生 ES modules、共享表单/表格、按需加载、请求取消、角色权限和窄屏布局。新增能力和状态由后端提供，证书续期按钮明确显示不可用原因；其余动态 API 继续使用具名包装器，不宣称全前端 strict。

持久计量复用请求对象及响应通道，并在归还前清空上下文和账户标识。保留 WAL/FULL、64 KiB 预留、提交成功后转发及取消的确定结果。短样本确认分配减少；磁盘耗时有明显波动，没有足够证据宣称吞吐或 RSS 提升。

只执行受影响的 Go 回归、accounting 定向 race、前端相关脚本、类型/生成契约、编译和定向 vet。新管理程序通过本机真实 HTTP API 联调；Linux 测试源码通过交叉编译。本轮未执行完整 Go/前端套件、真实浏览器、Linux systemd/netns/防火墙运行验收或长期负载测试。[具体结果与样本](validation/2026-11-26-recovery-resource-refactor.json)。

## 体积与分支

`scripts/clean-dev.ps1 -Dependencies` 清理已停止使用的测试数据库、旧二进制、缓存、截图、日志和 Node 开发依赖。执行前校验绝对路径、目录链接与运行进程；权限受限的旧目录单独跳过，继续清理独立缓存。源码、必要回归、Git 历史、许可证、文档引用图片及当前 Go/核心工具链保留。

本次释放 2,530.38 MiB（约 2.47 GiB）。清理后可读取文件总长度约 429.04 MiB，其中当前工具链占 414.65 MiB。Windows 的 `.cleanup-manual` 仍被文件系统权限拒绝访问，其大小未知，不计入统计；具体测量范围和残留记录见本轮验证 JSON。重新测试时加载 scripts/dev-env.ps1，并用 go mod download / npm ci 重建依赖。

交付分支为本地与远端 main。此前边界修复的历史验证仍见[原记录](validation/2026-11-26-boundary-refactor.json)，它不替代此次验证。
