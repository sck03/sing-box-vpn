# 审查问题修复与重构（2026-11-21）

本轮基于 f04d7c1 完成后续审查问题的实现。面向首次部署，仅维护当前数据和接口，不新增旧版本兼容或迁移。数据库 16、平台 6、节点 4、订阅 6、备份 8 保持各自当前版本；新增字段属于派生运行状态与类型化状态/任务响应。

## 模块边界

- controlstore.AppliedState 原子读取确认版本与配置；subscriptions_generation 负责后台操作的代际边界。
- subscription.AccountTemplates 负责账户模板依赖选择；正常编译、预览和账户分享使用同一编译器产生的有效模板。
- subscriptions_delivery 负责调度、摘要和完成记录，subscriptions_delivery_transport 只处理 HTTP/WebDAV、Gist、GitLab、Telegram 传输。
- subscriptions_runtime_merge 在配置、凭据和隧道发布提交阶段合并操作记录，避免锁外编译覆盖已完成投递；网络和核心验证不持有提交锁。
- fileBundle.subscriptionRuntime 统一运行状态、调度和活动投影的原子提交。SubscriptionStatusResponse 和 DeliveryResult 通过 panel-contract 生成前端类型。
- 前端继续使用原生 ES modules。JS 检查保持现有 checkJs；新增契约样例在严格配置下检查，不把整个前端描述为严格 TypeScript。

## 代码与文件清理

删除无调用方的 Options.ProxyPeer；备份/恢复的字节缓冲包装与 Build/BuildAvailable 便捷包装移入测试文件，生产只保留流式备份和显式编译模式。Reserve 仍支撑跨包账本恢复测试，ConfigTransaction 是网关注入的真实回调，均保留。许可证、有效回归夹具、开发工具链及可复用 Go 缓存不作为无用文件删除。

旧产物、本轮测试二进制、日志、截图及中断测试临时文件共 280 个文件、292,547,117 字节，已集中到 Git 忽略的 .cleanup-manual/。批量递归删除被自动审批策略拦截（blocked by policy），按用户指定的备用方案保留同一个手动删除目录。.test/ 只保留可复用 Go 缓存和空临时目录。过往已修复问题及历史性能样本可从 Git 历史追溯。

## 验证与边界

[验证记录](validation/2026-11-21-refactor.json) 记录本轮实际命令、结果和清理情况。新增回归覆盖并发发布、取消投递、远程规则、秘密隔离、后台队列和真实页面生命周期。性能基准只比较相同 4096 节点缓存的状态读取开销，不作为 VPN 吞吐或整机 RSS 的结论。
