## 模块与查询

`configuration_queries.go` 将选项查询与 HTTP 分离。`AppliedViewSince` 在单个 SQL 快照中读取两个修订号，确认版本未变时不返回配置正文。服务仅缓存不可变配置，供网关、隧道同步、选项与账户导出复用；待应用草稿、实时隧道观察和账户权限不会混入缓存。调用者禁止修改共享 map/slice；命令使用独立候选。新增并发与版本切换回归。

服务与运行实例从无约束字典改为明确 DTO，订阅/出站/分享选项也有生成契约。前端 configuration-api.js 纳入 strict 检查，保留原生 ES modules、现有控件、权限和窄屏布局。application 层统一手动命令及调度命令校验，manage 适配持久任务。

仅测试调用的 VPNGate defaults、账本 Reserve/Advance 包装移至测试文件；跨包账本夹具改走实际 Meter 认证、预留和结算接口。WAL/FULL、64 KiB 预留边界、撤权周期与发布恢复语义保持。
