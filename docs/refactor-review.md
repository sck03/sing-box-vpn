## 修复与行为

| 问题 | 最终行为 | 回归覆盖 |
| --- | --- | --- |
| 条件请求判定与正文发送不一致，绕过订阅下载次数 | HTTP 标准库决定响应；GET 200/206 前原子计数，其他无正文状态不计数；额度不足不发送产物 | 无效 ETag 前缀、弱标签、标签列表、HEAD、304、Range、多段 Range、412、416、并发限次 |

| 不可用的可选账户源阻断其他有效节点 | 编译记录实际 contributors；下载、投递、状态共用权益和新鲜度策略 | 可选源缺失、被过滤、实际贡献，以及必需/可选远程源过期 |

| 每次绑定扫描实例内全部凭据及 secret | 仓储按目标账户、实例和入站只查询关系，继续原子创建和独立随机凭据 | 查询范围、重复绑定、原子性与同库对比基准 |
| 单条账户任务与批处理重复维护发布路径 | 删除 executeAccount 和旧分发分支，回归改走真实 runAccountBatch | 发布失败、重试及不重复轮换 |

## 模块与前后端契约

subscription 只负责来源归属与编译；subscriptions_policy.go 统一输出可用性，subscriptions_response.go 处理最终响应计次。状态使用小型输出策略投影；正文配置复用现有不可变缓存，确认版本与账户授权仍实时查询。

绑定查询由 application 的窄仓储接口驱动，accounting 只返回所需关系。前端保留原生 ES modules、共享表单及窄屏样式；结果入口不会抢占配置草稿的吸顶区域。面板设置、管理员/MFA、用户分组、账户保存/归档及分享创建接入 Go 生成的查询/写入契约。移除旧的 configured-source 授权助手和重复 ETag 解析。
