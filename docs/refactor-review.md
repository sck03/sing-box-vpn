## 模块边界

- `certificates.Scheduler` 拥有修订缓存、扫描期限、退避规则和互斥状态；`RenewalSource` 隔离控制仓储、任务队列和 ACME 登记。
- `subscription.Schedule` 拥有轻量调度投影与到期判定。manage 只负责文件读取、账户状态查询与入队；投影没有节点正文、模板正文或秘密。
- `application.ExecuteSubscription` 是订阅任务唯一分发点。调度元数据仍只存在于内部任务，不允许公开 API 提交。
- 证书状态由 `certificates.CertificateStatus` 明确定义；Go 生成器同步前端状态模型和按操作区分的订阅命令。
- API、账户 API、证书字段模块启用独立 strict 检查，全部前端继续 checkJs；没有将未检查的 UI 描述为完全严格类型化。
- 配置发布继续使用现有 application 部署事务、精确服务计划和失败恢复；计费继续保持 WAL/FULL、64 KiB 预留、提交后转发与撤销检查。

## 资源与性能

证书修订未改变时 SQL 不复制配置正文，调度器复用已应用登记；扫描窗口内不重复读取 PEM 或尝试记录。订阅调度只读取期限投影。表格使用渲染时的动作签名，避免刷新时再序列化旧动作对象，并正确处理对象原地修改。

本轮没有更改计费算法或放宽持久性。微基准只用于记录当前开销，不作为 Linux VPS 吞吐、RSS、实际用户容量或本轮百分比收益。现有持久预留合并、授权缓存、状态共享和分页保持。
