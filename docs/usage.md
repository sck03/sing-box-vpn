# 使用指南

[项目首页](../README.md) · [实际验收记录](unified-management-status.md)

侧栏常用入口为「运行概览」「节点管理」「用户与分享」「系统设置」。相关功能通过页内标签切换；VPNGate、路由、出站和订阅编排在默认收起的高级功能中。搜索可直接找到 Argo、备份、分享或证书，详见[导航与日常使用](navigation.md)。

## 登录与安全

安装要求空目录，管理员密码 8–72 字节。默认只监听 `127.0.0.1:2096`。远程使用 SSH 转发；浏览器进入后可以创建 operator（运行控制和日志）、viewer（状态与用量）角色。管理员密码、角色或禁用变更会撤销旧会话；最后一位有效管理员不能禁用。

密码长度按 UTF-8 字节计算，页面与后端使用同一规则，支持中文密码。公开用户页允许从其他网站点击进入；管理 API 继续检查同源、Cookie 和 CSRF。

可有多个后台账号，共同管理全机资源，并非各管理员独立租户。用户通过专属分享链接查看用量和下载配置，无需后台账号。日常只管理权益、入口绑定和分享；高级用户分组用于同一用户拥有多份权益时集中停用。链接内部保存随机令牌的哈希，用于私有下载与撤销，为同一权益增加链接不会产生额外流量额度。

「管理员安全」支持 TOTP：验证当前密码生成密钥，录入认证器，再提交六位验证码确认。确认前旧登录方式仍有效；确认后重新登录。丢失认证器时在服务器执行 `sudo sb reset-admin`。秘密仅在授权查询或创建时展示，不写进默认列表。

通过「公网访问 → 配置面板访问」选择直接 HTTPS 或 HTTPS 反向代理，校验并查看完整配置后保存，再在服务器执行 `systemctl restart sb-panel`。直接 HTTPS 可使用「节点管理 → 证书管理」已申请/导入的证书；证书域名、期限、私钥匹配及面板端口冲突均会校验。TLS 握手读取当前证书文件，续期后新连接使用新证书。详细 DNS、端口与 Nginx 示例见[公网访问与系统服务](public-access.md)。

公网 HTTPS 反向代理示例 `/etc/s-box/panel.json`：

```json
{
  "listen": "127.0.0.1:2096",
  "public_url": "https://panel.example.com",
  "certificate": "",
  "key": "",
  "trusted_proxy": ["127.0.0.1/32"]
}
```

代理必须保留 Host，设置 `X-Forwarded-Proto: https`，禁止访问日志记录下载 URL。仅信任实际代理地址，不填写整个公网网段。变更后 `systemctl restart sb-panel`。也可填写 `certificate` / `key`，直接使用 TLS。CSP、同源检查与 CSRF 始终启用。

## 首次可用流程

1. 在「入站与发布」核对 VPS 地址、五协议入口和端口；防火墙只管理项目自己的链，云安全组需另行放行。
2. 在「权益与用量」创建权益。界面以 GiB 输入，数据库记录字节，留空不限，0 是零额度；1 GiB = 1073741824 字节。
3. 绑定普通入口；从已应用的入口列表多选，留空绑定该实例全部启用入口。可填 UUID/密码，否则分别随机生成。
4. 在「系统设置 → 公网访问」先配置可达 HTTPS 地址；等绑定任务成功，在权益行点击「分享」，复制并保存只展示一次的用户页地址。记录和撤销位于「用户与分享 → 分享链接」；无需填写授权 ID、第二个有效期或下载次数。用户页展示权益状态、用量、期限与允许下载格式。
5. 用原生 sing-box/Mihomo 配置连接。URI 自签 TLS 导入限制见兼容性文档。

批量绑定最多 100 个权益，各自生成独立随机凭据，全部校验成功才提交。入站「关联影响」显示权益、订阅输出和下载授权；删除前再次列出影响。

下载不会激活首次使用权益。首次成功代理认证开始有效时长；每 N 日按日历和时区计算，每月 29/30/31 日在短月取月末。周期策略创建后不可原地修改，变更套餐应新建权益；编辑额度、名称、绝对到期和禁用不会重置已消费量。普通/VPNGate 绑定同一权益共享额度。

`charged_bytes` 含已持久预留；上传/下载是已结算有效载荷。正常退出退还未用额度；每次崩溃最多保守占用每权益、每活动实例/账期池的未用预留 64 KiB，连续崩溃可累积。运行时授权缓存最长 250 ms，并由集中检查与 I/O 检查执行；数据库延迟、线程调度和在途数据使它不构成绝对断开时延保证。周期切换关闭旧周期连接，客户端重新连接。

## 配置与日常操作

权益的「绝对到期时间」可以留空。列表和用户页显示实际到期时间，取绝对期限与“开始时间加持续时长”两者中较早的一项。首次使用型权益会在第一次代理认证时开始计时。改名会保留原来的期限设置。

暂时停用请选择「编辑 → 禁用」。永久退役请选择权益行的「更多 → 归档」。归档会释放一个权益名额，撤销此权益的凭据和专属分享。原 ID 永久保留，在「权益范围 → 归档记录」中可查看用量和历史账期。需要恢复服务时请创建新权益并重新绑定。停用、过期和额度用尽的权益在归档前仍占用名额。

编辑保存在浏览器草稿。先「预览差异与校验」，再「校验并应用」。任务成功才更新实际配置版本；失败保留期望配置和阶段，回滚已发布配置及原服务状态。版本冲突返回 409，应重新载入核对。

预览按输出列出可发布状态、大小和诊断。不支持的协议/客户端组合会阻止保存；暂时缺少来源数据则明确标记输出不可用。校验使用完整当前草稿，准备好的远端来源随应用任务保存，不在预览时改写运行缓存。

Hy2/TUIC 范围使用逗号分隔的 `30000:30100, 30200`；转发到该协议的主入口，多同协议入口不会全部获得主入口的跳跃范围。指定 TUIC 导出端口必须是已配置范围。多个入口不能复用同监听端口。

高级 JSON 经过字段、资源引用、循环依赖及核心校验。VPNGate 的受保护路由不能被普通路由覆盖。WireGuard 需要自行提供服务商合法配置；本项目不自动注册 WARP 账户。

WireGuard 统一配置在「出站与隧道」的端点列表。快捷 WARP 分流使用 tag 为 `warp-out` 的端点，没有第二个 `app.warp` 配置入口。普通服务端默认提供 `dns-local` 解析器，域名出站可选择其他 DNS tag。协议出站表单按类型显示认证、TLS/Reality、WebSocket、出站组和链式上游字段。

「运行概览」支持启动、停止、重启及开机启动切换。操作员可以进入 VPNGate 页面控制运行和查询出口；国家及入口配置仍由管理员管理。网关连接超时为 5–180 秒，健康检查为 1–300 秒，连接与待拨号容量为 1–1024，前后端使用同一限制。

Argo 固定模式需要 Cloudflare tunnel token 和域名，Cloudflare 配置应指向选择的本机 VMess 端口。临时模式域名来自本次 cloudflared 运行日志，变化后重编译导出。TLS 自签后端仅临时隧道本机连接使用显式 no-tls-verify。外部 Cloudflare 服务可用性独立于本机状态。

已发现的临时域名会保留到本次 cloudflared 运行结束，日志滚动不会清空域名。BBR 恢复失败可以重试，恢复信息只在成功后清除。操作员可在维护页查看自己发起的配置任务详情；表格次要动作收纳在「更多」，手机宽度下改为带字段名的卡片。日期支持秒，未修改日期的其他表单编辑保留原值。

手机列表保留独立排序入口。账户用量更新保留焦点，只有策略版本变化才阻止旧操作。账户导出支持能力目录中的全部格式，提供复制和下载；二维码按选择的节点生成。用户页支持刷新用量和明暗主题。

ACME：先保存未绑定资产，再申请，成功后绑定入口。申请与续期使用内置 lego Go 库，无需安装 Certbot、Python 或 lego 命令行。域名的 A/AAAA 记录须指向本机，端口 80 必须空闲并从公网可达；当前只接入 HTTP-01，DNS-01 与泛域名暂不提供。

后台每 12 小时最多尝试一次资产，证书不足 30 天或缺少 ACME 登记时尝试；只重启使用该资产的活动实例并等待新核心心跳。失败保留现有证书；已签发但发布失败时，重试复用已签发结果。恢复保留自动续期属性；证书页显示已登记、待自动登记或手动更新。仅支持当前 `acme` / `import` 资产，不迁移旧 Certbot 数据。导入 PEM 校验域名、期限与私钥匹配。

## 备份和救援

「维护」下载全量 age 认证加密备份，口令至少 12 字节。数据库及引用证书先取得一致材料快照，再流式归档加密。在线恢复只替换配置和证书，保留当前账户、凭据、流量、管理员及下载撤销；不恢复旧额度。先预览再应用。

当前数据库 schema 15，备份容器格式为 8，两者独立；只接受含 schema 15 数据库的备份。加密文件最多 96 MiB，数据库最多 80 MiB；HTTP 恢复使用 multipart/form-data 的二进制 `backup` 文件及 `password`、`apply`、`revision` 字段，密文暂存到磁盘后流式解密到私有目录，完整认证后才检查和发布。应用时必须提供预览对应的配置 revision。同一面板进程同时只处理一个备份/恢复请求，重复请求返回 429。旧数据库或旧备份请勿放入新部署目录。

「用户与分享 → 分享链接」的列表支持服务端分页与状态搜索。高级输出和已有链接可带独立下载限制，普通账户分享默认跟随权益。失效记录最多保留 1,000 条/30 天后回收，旧令牌不会因此恢复有效。「任务与日志」支持删除已结束任务、标记处理、批量清理与保留策略；默认保留 200 条/30 天、8 MiB 详情，回收详情仍保留最终状态。排队和运行中的任务不可删除。运行日志在专用 `sb-vpn` 命名空间中自动轮转，支持筛选、下载及项目历史清理。界面主题可切换，常用入口固定显示，高级区可收起并记忆；后台任务进度在所有页面可见。

灾难恢复到空目录，通过 `yg-vpngate panel --root <空目录> restore` 从 stdin 提交 JSON，字段 `backup_path`（本机加密备份文件路径）、`password`、`username`、`new_password`。口令通过 stdin 传入，不放入命令参数。恢复后全部权益禁用、下载令牌撤销、管理员重建，先对账再启用。复制运行时与验证核心到新目录后执行 `panel recover`、`panel validate`、`panel install-services`。面板配置恢复为回环默认值。

`sb status` 查看摘要；`sb diagnose` 查看服务与日志；`sb recover` 从数据库已应用版本重建投影。不要手改生成的 app.json、sb.json 或 subscriptions/config.json，它们会被重建覆盖。

凭据变更失败后先看概览中的目标、已发布、已加载版本；后台会自动补发布，不必重复点击轮换。手动停止的核心在下次启动时加载。订阅刷新显示“使用旧缓存”时，可继续下载已有有效内容，同时应检查来源错误；任务完成不等于所有上游刷新成功。

`sb-recovery.timer` 每约 5 分钟重试 failed 服务，保留手动 inactive 状态；查看 `systemctl status sb-recovery.timer` 和 `journalctl -u sb-recovery`。修复磁盘或配置后可本机执行 `yg-vpngate panel recover-services` 立即尝试。超过 7 天、无已保存/已应用引用的项目导入或恢复证书目录会回收，长期未保存草稿中的证书需重新导入。

执行 `sb` 打开维护菜单，已安装版本从管理器读取；`sb upgrade` 自动下载并校验最新正式包，不限制 v4/v5 等主版本号。管理器和受管核心一起校验和替换；主动停止的服务保持停止，enabled 状态不变，失败恢复旧二进制。数据格式仍须匹配当前平台，不能用任意官方核心代替受管核心，否则没有本项目额度守卫。

`sb uninstall` 在确认后删除程序、配置、账户、证书和用量记录；无交互场景须明确指定 `sb uninstall --yes`。卸载只处理带项目标记的默认目录与项目服务，保留共享系统软件包。卸载不依赖 GitHub 或重新下载发行包。

面板升级任务先验证和替换核心，再由独立 systemd 服务重启面板。重启失败恢复上一程序，最终结果查看 `journalctl -u sb-panel-upgrade-restart` 与面板服务状态。上一发行包及失败材料保存在 `/opt/sing-box-vpn.update.*`，确认新版本后由管理员清理。

## 托管节点和模板编辑

托管 VMess 的传输固定为 WebSocket。表单可设置路径、Host、Early Data 字节数及请求头；高级 JSON 与表单遵守相同校验，gRPC 等不受支持的服务端字段会返回明确错误。Reality 常用参数已有表单入口。账户实际认证凭据仍由绑定/轮换管理，节点字段不能替代账户授权。

订阅模板资源先选择模板，再切换「策略组」「远程规则」「本地规则」。共享规则资源和账户模板覆盖在折叠区；列表为空时保留创建操作，减少无效工具栏。批量连续账户操作可合并发布，各任务仍分别展示结果；失败任务应先检查已提交状态，不能盲目重复轮换。

账户自定义 UUID 会自动规范为小写标准格式。同一实例、同一入站禁止重复有效身份；更换大小写或使用花括号/紧凑 UUID 不构成新的凭据。轮换必须改变有效认证材料，TUIC 可以保留 UUID 并更新密码；成功后原代次立即撤销。

配置保存前可预览，保存后点击通知中的「查看结果」检查应用任务。字段错误会定位表单；遇到版本冲突时保留当前草稿，核对服务器版本后重新载入。维护页的任务列表按页读取，概览只展示最近/进行中的部分任务及独立总数。
