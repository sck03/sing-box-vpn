# v3 重构验收记录

> 历史研究与验收记录：保留当时的版本、命令和结果，不作为 v4 部署操作指南。当前实现与验证范围见 [统一管理实施记录](unified-management-status.md)，安装步骤见 [v4 使用指南](usage.md)。

本轮依据 2026-11-16 的重构方案执行，源码版本为 `v3.0.0`。使用新的管理模型和订阅 schema 1，
仅面向空目录新部署，不提供 v2 数据或旧下载接口迁移。使用方式见 [订阅文档](subscriptions.md)。

## 交付范围

| 范围 | 已实现行为 |
| --- | --- |
| 基础修复 | 启用保留地址和令牌、独立重置、独立公网基础地址、只读查看、失败恢复、按内容及核心身份复用校验 |
| 多客户端核心 | 类型化节点模型、local/inline/remote 来源、集合处理、客户端能力与适配器、声明式模板、规则资源、预览和原子快照 |
| 日常管理 | 独立分享、范围/到期/次数限制、ETag、定时刷新与退避、流量/到期、诊断日志、Webhook/Telegram 通知、加密备份和回收站 |
| 可选扩展 | 按需运行的回环 Web 管理、实际协议连接检测、HTTP PUT/WebDAV/secret Gist 分发，保留原 Telegram/私有 GitLab |
| 整理 | 删除重复的旧客户端生成器及相应旧结构测试，更新菜单、架构、使用、开发和兼容性文档；打包包含依赖校验和与第三方许可证 |

新模块 `internal/subscription` 负责纯模型、解析、处理与渲染；`internal/manage/subscriptions_*`
负责存储、服务、授权、调度、备份、Web 和分发。扩展协议或客户端从能力登记和适配器开始，
避免在菜单或 HTTP 处理器内另建一套转换逻辑。运行时不需要 Node.js、Python 或数据库服务。

## 验证结果

- 全量 `go test ./...`、`go test -race ./...` 通过，真实核心使用 sing-box 1.14.4、Mihomo 1.19.33，
  开启 `RUN_UDP_IDLE_TESTS=1`；最后的分享/清理修正另通过 manage 包竞态回归。
- 普通/VPNGate 两套五协议、原生配置、URI 和 HTTP provider 共 72 条 TCP/UDP 链路通过。
  provider 测试先断言下载成功和节点完整，避免回退路径掩盖订阅错误。
- Linux 虚拟机通过 OpenVPN/netns 隔离、IPv4/IPv6 多端口防火墙、systemd 启动与重试恢复、
  Argo 服务恢复和保留无关覆盖设置的验收。
- 工作流覆盖首次必需来源应用、304、失败保留旧快照、资源调度、服务/备份回滚、错口令、损坏备份、
  路径穿越、恢复路径重映射、分享撤销/限次持久化以及无远端来源时的旧缓存清理。
- Web API 的鉴权、跨源拒绝和只读预览通过；真实 AnyTLS 节点按需检测通过；PUT、WebDAV Basic、
  Gist 可见性检查及未变化输出不重复分发通过本机 HTTP 回归。
- `go vet`、gofmt、ShellCheck、Bash 语法和菜单表单脚本检查通过；Linux amd64/arm64 静态安装包构建并校验 SHA256。

## 持续运行与资源测量

Windows amd64、Go 1.27.3、i5-9400F；HTTP 持续测试使用 1 KiB 快照、8 个请求 worker，运行 10 分钟：

| 指标 | 结果 |
| --- | --- |
| 完成请求 | 79,688 |
| 失败请求 | 0 |
| GC 后 HeapAlloc | 测试前 769,616 B，测试结束并关闭连接后 1,138,496 B |
| goroutine | 测试前 6，回收后 2 |

旧基线 `70c56fb` 与新实现分别执行 7 次 CLI 动作：只读 `links` 的核心子进程调用由每次 1 次变为 0 次；
重复应用相同分流由每次 3 次变为 1 次（只保留版本查询）。耗时采样受到并行测试干扰，不作为性能收益结论。
渲染分配基准及复现命令见 [性能记录](optimization.md) 和 [开发文档](development.md)。

## 验证边界

- Surge/Mac、Loon、Quantumult X、Surfboard、Stash、Egern、Shadowrocket 等专有客户端完成格式结构与字段映射测试，
  没有真实设备导入和连接验收；能力不足默认拒绝，显式选择跳过后才排除节点。
- Web 页面已实现，HTTP/API 回归通过。本次浏览器工具无法导航，原生窗口后备访问也因窗口最小化失败，
  因此未完成浏览器视觉与点击验收。
- 分发测试使用本机服务，没有向实际 Telegram、GitLab、WebDAV 或 Gist 账户发送测试订阅。
- 持续运行证据限于上述 10 分钟 HTTP 压测和资源回收，不代表数天在线、整机 RSS、生产负载或代理吞吐测试。
  按需检测结果包含进程启动、协议握手和 HTTP 请求时间，不是纯 RTT 或 UDP 吞吐。

提交到分支与发布正式 Release 是独立动作。`main` 推送不会替换安装器下载的最新正式包；本次可使用本地构建包部署新版本。
