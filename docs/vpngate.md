# VPNGate 实现与运行边界

[使用指南](usage.md) · [平台架构](architecture.md) · [验收记录](unified-management-status.md)

目标是保留普通五协议节点，再提供一套可临时选择的 VPNGate 家宽候选节点。
sing-box 核心支持在线更新至官方最新稳定版，最低 1.14.0，测试基线 1.14.4。
Go 构建工具链为 1.27.3；发行包包含 Linux amd64/arm64 静态网关。
v4 管理、配置、证书、订阅、更新和资源下载由 Go 管理器提供；Bash 仅保留安装、升级与入口封装。

普通节点与 VPNGate 节点各有 VLESS Reality、VMess-WS、Hysteria-2、TUIC-v5、AnyTLS。
普通入口保留自己的端口和路由。VPNGate 入口使用独立端口与 TLS/Reality 材料，代理凭据绑定独立权益，同国家
五种协议共用一个 OpenVPN 出口。切换 VPNGate IP 不改变入口链接。

```text
客户端 → VPNGate 专用五协议 sing-box 入口
       → 回环地址上的认证 SOCKS5
       → Unix socket
       → netns 内的独立工作进程
       → OpenVPN tun0 → 指定国家的 VPNGate 节点
```

出口采用进程隔离，避免宿主机进程调用 setns 引起线程或子进程进入错误命名空间。
netns 先设置 OUTPUT/INPUT 默认 DROP，仅允许 tun0 业务流量、回环通信，以及带专用
mark、远端 IP/端口明确匹配的 OpenVPN 外层连接。宿主机默认路由不改变；转发/NAT
规则限定到本项目 veth/subnet，停止后按所有权逐项清理。

工作进程显式使用隧道内 IPv4 DNS；IPv6 目标不转发。SOCKS5 支持 CONNECT、UDP
ASSOCIATE，TCP/UDP 中继只监听回环地址，必须认证。业务 socket 不具备 OpenVPN
外层 mark，因此隧道消失后不能经 veth 回落到 VPS。

`max_connections` 为 1–1024，默认 128。客户端连接与 worker 转发流分别限制到该数量，正在拨号的流也占用转发额度；一个已接入客户端不会抢占自身建立转发所需的名额。UDP 控制连接持有一个关联套接字，不重复占用准入，每个目标流仍受转发上限约束。变更出口或撤销授权时，两类连接和未完成拨号都会关闭。

国家代码持久化。节点源缺少国家、国家不符、无效 IP，或 profile 含脚本、插件、
任意文件引用、其他 remote 时拒绝。连上后查询实际出口 IP 的国家和运营商；
未知或不匹配时阻断。默认排除已知自营机房与 hosting，支持 ISP 严格模式和 ASN
允许列表。Geo/ASN 按源/IP 缓存 15 分钟且最多 128 项，默认健康间隔 10 秒。
节点列表缓存一分钟，并发刷新合并；探测 HTTP 连接按隧道复用。
手动“刷新候选”任务等待实际抓取结果，最长抓取预算 30 秒，控制服务写入预算为 35 秒。刷新 I/O 不占用启动、暂停和重载的控制互斥槽。任务结果为 passed（成功）、partial（节点已更新但缓存写入失败）、cached（抓取失败，继续使用同来源旧缓存）或 failed（无可用结果），不再把 HTTP 受理当作刷新成功。
状态接口 source_refresh 同时提供节点数量、失败来源数量、最近完成时间、最近成功时间及不含来源 URL 的原因；进程刚启动时最近成功时间可为空值，不伪造磁盘缓存的抓取时间。“查询出口验证”和任务详情显示这些状态。只读配置中的 gateway.sources 整体脱敏，校验诊断也不会输出其中的令牌。
磁盘候选及上次节点按完整来源列表归属，切换来源清空候选和失败冷却、取消后台刷新。
刷新按来源代次拒绝过期响应；新来源不可用时不复用已移除来源，重启也检查缓存归属。
出口 IP 归一化后再与 VPS 比较，同一地址的 IPv4/IPv4 映射写法不能绕过校验；
Geo 查询和缓存也使用归一化地址。ASN 仅接受正的 32 位整数，不对小数作截断匹配。
节点源采用流式 CSV 解析，保留 16 MiB/1500 候选上限；断流、超限或 CSV 引号结构损坏时
拒绝新列表，保留同来源有效缓存。达到候选上限后继续检查后续 CSV，不再解码额外 profile。
profile 指令最多三个参数，使用固定字段缓冲并提前拒绝多余参数，避免无效长行大量分配。
列表读取限制与实际代理流量独立，不限制单次下载、视频或累计传输量。
健康探测遇到临时网络 / 元数据故障时先阻断，再在原隧道上间隔 2 秒重试两次。
错误国家或筛选策略不符直接拒绝；重复启动或重载相同设置保持已验证隧道。
启动先尝试一个本地保存的同国候选，同时刷新节点源；仍重新校验实际出口。
启动探测也支持临时故障重试；一次节点刷新总计最多 30 秒，包含等待其他刷新。

当前只监听和导出一个国家的五个 VPNGate 入口。各国家端口和凭据仍保存：韩国激活后，
日本入口关闭；重新激活日本会恢复原日本链接。停止出口保留入口配置，节点不可用；再次启动
沿用原链接。普通节点独立于 VPNGate 的启停和国家选择。

家宽筛选是候选识别，不是住宅接入认证。固定模式只重连选定节点；动态 IP、节点
满员或下线仍可能导致不可用，严格模式不会因此跨国或回落到 VPS。

在「权益与用量」绑定 VPNGate 入口，随后按运行实例导出或创建分享。
账户下载使用 `/u/<令牌>/<格式>`；自定义输出使用 `/s/<令牌>/<输出ID>` 读取已验证快照。
VPNGate 客户端手动选择当前国家节点，不提供普通节点或 DIRECT 回退；混合集合使用独立 VPNGate 策略组。
国家和端口配置在 VPNGate 页面保存并应用，代理凭据通过权益绑定/轮换管理，普通入口保持独立。

页面支持绑定证书资产、设置 Reality 握手参数、Hy2 跳跃/TUIC 转发端口，以及 Geo URL、出口探测 URL、隧道 DNS 与 ASN 筛选。连接超时 5–180 秒、健康检查 1–300 秒、连接和待拨号容量 1–1024；保存前与网关启动使用同一校验。操作员可查询与控制运行，配置权限仍归管理员。
OpenClash 使用账户来源的 Mihomo provider 输出，沿用路由器自己的 DNS 与策略。
详细设置见 [订阅与 OpenClash](subscriptions.md#openclash-与证书)。

TCP 不设置定时重连。UDP 的空闲期限由双向收发共同更新，持续单向上传、下载也保持会话。
无效包、分片、零目标端口及其他源端口不延长关联寿命；退出等待控制读取和全部目标转发回收。
健康探测按当前隧道复用连接；隧道进程退出可立即中断正在进行的探测。UDP 控制连接关闭
时同时取消未完成的拨号并释放会话。入口设置不会重启 OpenVPN，重复导出也不触发服务重启。
代理和 worker 的监听停止或失败时取消全部会话，等待握手、拨号与中继退出后再完成清理。
后台节点刷新也在释放守护进程锁前取消并等待；停止后不再接收刷新任务。
代理套接字与待完成 worker 拨号共用容量上限，先预约再拨号；成功时原位转为连接，失败时释放。
出口撤销会取消正在等待 worker 的请求，旧代次的拨号不能在新出口恢复后重新接入。
新 UDP 目标异步解析，每个目标由独立协程按顺序发送，阻塞目标不拖住其他端口。每个关联限制
8 个并发拨号，每个目标最多排队 64 包；排队及写入中的缓冲容量最多 256 KiB，单目标最多
128 KiB，超限丢弃新包。接收与排队缓冲均复用，关闭时取消拨号及写入，等待协程退出后回收。
合法 UDP 回复若加上 SOCKS 地址头超过单包上限，仅丢弃该回复，保留目标会话和源端口；
worker IPC 帧本身超过 65,507 字节或被截断时仍关闭连接，避免失去帧边界后继续转发。

只维护现代模板，旧内核、双模板和旧 geosite/geoip 数据库不再生成，也不导入旧版配置。
首次安装要求空目录；control.db 保存 desired/applied 配置，app.json 为可重建投影，重复初始化拒绝覆盖。
修改使用稳定资源 ID；Hy2 单端口转换为等值范围。候选配置通过校验后写入持久任务，
发布、服务应用与心跳确认成功后才更新 applied；失败恢复原配置与服务状态，账本与撤销不回滚。
证书指纹来自各入口实际证书。`sb recover` 从已应用数据库状态重建投影。

验收随代码交付：

- Go：危险 profile、国家/固定模式、ASN、内核规则、过期认证、TCP/UDP 和碎片。
- Go 管理：两套五协议、拒绝重复初始化、独立设置、凭据隔离、链接恢复、非法配置保护、跳跃与手动组、核心回滚、订阅限制。
- 持续会话：单向 UDP 上传和下载分别运行 65 秒，验证没有空闲误判或会话重建。
- UDP 并发：慢 DNS 时已有目标继续收发、等待包按顺序转发、拨号/队列有界、关联关闭取消全部等待。
- 实际协议：两套 sing-box/Mihomo 原生配置、HTTP provider 和三协议 URI 共 72 条 TCP/UDP 链路。
- Linux：受控 OpenVPN TLS、隧道 DNS、TCP/UDP、杀隧道后的已有/新连接阻断、
  停用状态重启恢复、错误出口国家拒绝。
- CI 通过后才发布两种架构与 SHA256；测试不冒充公共节点或特定 VPS 的在线结果。

生产要求 Ubuntu/Debian + systemd、root、IPv4、TUN/netns。稳定版下载须校验。
配置不兼容时保留旧核心，服务启动失败时自动回滚。
仓库不包含运行密码、私钥、节点缓存、临时工具链和研究源码副本。
VPS 不需要 Python 或 Certbot；证书申请与续期使用内置 lego Go 库，OpenVPN 仍由系统包管理器安装并用于 VPNGate 隧道。
